Scope: Canvas course drawer; fluid student/course/exam layouts; compact overviews; viewport editor and full-screen preview; separate full-screen immutable review pages; course+branch teacher assignment and enforcement; 30-day persistent sessions. Use pinned InstUI 11.7.10. English/Vietnamese, light/dark, responsive 390–1920px. No changes to public entrance or managed handles except integration of the owning chat's completed commit.

Global constraints: isolated worktree; preserve all unowned edits; agents own disjoint files and do not commit until controller completes Graphify refresh/check and verify:local. Targeted tests during development. Never run semantic Graphify APIs. Production DB and deployment are separate release gates. Integrate auth migration 54 baseline before packaging next migration. ## Task 3: Teacher assignments foundation and API
Own new migration 20261106010000_course_teaching_assignments.sql, new src/features/teaching/assignments.ts/contracts, lib authorization permission definitions, new teacher assignment API routes, teacher assignment SQL tests and Azure generic transport allowlists as needed (do not edit scripts/azure-core or migration job package; controller owns release packaging). Student-safe teacher read may be added to existing course response or GET with enrollment checks, exposing names/handles only and historical enrollment branch.
Shared exported interfaces required by task 4: assertCourseTeaching(actor: Actor, permission: BranchScopedPermission, courseId: string, branchId: string|null): Promise<void>; teachingCourseScope(actor: Actor, permission: BranchScopedPermission): Promise<{all:boolean,branchIds:string[],assignments:Array<{courseId:string,branchId:string}>}>. Base operation permission is always required. teaching.scope.all bypasses assignment only in its allowed branch/global scope; unknown branch historical data only globally privileged scope-all actor. Everyone else requires active exact assignment/membership and base capability. No global permission bypass for ordinary instructor. Task 4 consumes these. Coordinate interface changes explicitly.
