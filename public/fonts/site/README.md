# Site fonts

These unmodified WOFF2 files are self-hosted copies of the Google Fonts faces previously loaded by the root layout. Family names, normal styles, weights, Unicode ranges, and `font-display: swap` are preserved in `src/app/fonts.css`. Filenames include the first 12 SHA-256 characters for immutable caching. No font binaries were modified.

Retrieved 2026-09-21 with a Chrome 130 user agent from:

- [Newsreader CSS](https://fonts.googleapis.com/css2?family=Newsreader:ital,wght@0,400;1,400&display=swap), retrieved 2026-09-24 for the learner mentor voice (DESIGN.md); [upstream](https://github.com/productiontype/Newsreader); license: `newsreader-OFL.txt` ([Google Fonts license source](https://github.com/google/fonts/blob/main/ofl/newsreader/OFL.txt)).
